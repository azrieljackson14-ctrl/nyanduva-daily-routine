# Nyanduva Daily Routine

This project showcases the daily routine of Nyanduva Gustavu, an employee based in Arusha. The website is designed to provide a clear and structured view of her daily activities.

## Project Structure

```
nyanduva-daily-routine
├── public
│   ├── index.php          # Main entry point for the website
│   ├── style.css          # CSS styles for the website
│   └── script.js          # JavaScript functionality for user interactions
├── java
│   └── RoutineService.java # Java class for handling routine-related logic
├── includes
│   ├── header.php         # Header structure for the website
│   └── footer.php         # Footer structure for the website
├── data
│   └── routine.php        # PHP script defining the daily routine data
├── README.md              # Project documentation
└── composer.json          # Composer configuration file
```

## Features

- **Daily Routine Display**: The website presents a detailed schedule of Nyanduva's daily activities.
- **Responsive Design**: The layout is designed to be user-friendly and accessible on various devices.
- **Dynamic Content**: JavaScript is used to enhance user interactions and potentially update content dynamically.

## Setup Instructions

1. Clone the repository to your local machine.
2. Navigate to the project directory.
3. Run `composer install` to install the necessary PHP dependencies.
4. Open `public/index.php` in your web browser to view the website.
